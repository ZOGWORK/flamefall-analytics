The problem

Future cabins move towards more oxygen and less pressure. The evidence is scattered.

Source official challenge brief, Flame in Freefall: suit 100% O2 at 4.3 psi; Moon atmosphere “30% or greater … 10.2 psi or less”.

  • 26 records come back from the repository for “combustion”; 24 are combustion science.
  • 25 per-test tables are attached to them, in different shapes, units and encodings.
  • Droplets, gas flames, solids and smoke obey different physics. We never pool them.
  • Three rules on every page: a source under every number · “no data” is an answer · estimates, never verdicts.

Source PSI Data Repository search “combustion”, retrieved 14 Nov 2026 through its public endpoints; snapshot in data/psi/.

What “SI-powered” means here
  • Search returns the measured statements themselves, with sources. No generated text, so no invented numbers.
  • Ranking uses a written formula with visible weights. Moving one weight by 0.10 changes the top three, and the page says so.
  • Every estimate shows its distance to the nearest real test and is marked DEMO outside the tested range.

Source data/models/*.json written by scripts/train_models.py, seed 42; fold membership in data/cv_splits.json. Droplet and solid data are never pooled. Row-wise validation would have reported 0.89 and 0.65: grouped validation is the honest figure.

Checked against primary sources

We went back to the tables. Fourteen statements changed.

  • A “missing” NASA memo was found under its real file name: 126 solid-fuel tests transcribed, every row checked against the page, 0 mismatches. NASA/TM-20210011385
  • “85% oxygen” is a burner feed, not a cabin atmosphere. It appears only in inverse-flame tables; chamber oxygen stops at 40%. PSI-159 and PSI-10 experimental tables
  • 3,150 W was an average, not a peak. Peak values exist for one flight only: 3,217, 3,080 and 1,507 W. ICES-2024-365, Table 2
  • Lunar-gravity numbers do exist, as preliminary slides from one flight. Shown with that label. NTRS 20250010653
